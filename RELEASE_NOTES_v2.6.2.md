# SteamVault v2.6.2

> Self-contained application — available as a full Windows Setup Installer or Portable Standalone executable. No .NET runtime required.

---

## 📦 Installer vs Standalone Portable — Which should you choose?

> [!TIP]
> **Windows Setup Installer (`SteamVault-Setup.exe`) [★ BEST & RECOMMENDED]**
> The complete desktop installation experience. It automatically detects your Steam installation directory, creates Start Menu & Desktop shortcuts, includes a clean Windows uninstaller, and integrates with the app's updater.

> [!NOTE]
> **Portable Standalone (`SteamVault.exe`)**
> A single, self-contained `.exe` file. No separate .NET installation is needed.

---

## What's New

### 🔄 OpenSteamTool DLL Refresh
* **Always Refreshes OpenSteamTool Files:** SteamVault now replaces the OpenSteamTool DLLs in the configured Steam folder on every launch, so users receive the current bundled DLLs even if older copies are already installed.
* **Reliable Portable Install:** The DLLs are embedded in SteamVault, allowing both the installer and standalone app to refresh them in the correct Steam folder.

---

## 💻 Requirements

* **Windows 10** (1809+) or **Windows 11**
* Steam must be installed

---

## 📥 How to Install

### Option A: Windows Setup Installer (Recommended)
1. Download `SteamVault-Setup.exe` from the Assets section below.
2. Double-click the installer and follow the setup wizard.
3. Launch SteamVault from your Desktop or Start Menu.

### Option B: Portable Standalone
1. Download `SteamVault.exe` from the Assets section below.
2. Place it in any folder and double-click to run.
